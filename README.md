# MySQL Assignment 2 – Querying Data

## Overview
This repository contains my solutions for **MySQL Assignment 2**, completed using MySQL. The assignment focuses on retrieving, filtering, sorting, grouping, and combining data from related tables.

## Database Tables
- `employees`
- `departments`
- `location`

## Topics Covered
- `SELECT` and `DISTINCT`
- Column aliases using `AS`
- Filtering records with `WHERE`
- Updating missing values with `UPDATE`
- Sorting results with `ORDER BY`
- Limiting results with `LIMIT`
- Aggregate functions: `SUM()`, `MIN()`, `MAX()`, `AVG()`, and `COUNT()`
- Grouping data with `GROUP BY` and filtering groups with `HAVING`
- Joining tables using `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`

## Tools Used
- MySQL
- MySQL Workbench

## How to Use
1. Download or clone this repository.
2. Open the `.sql` file in MySQL Workbench.
3. Select the appropriate database.
4. Run the queries to view the results.

## Learning Outcome
This assignment helped me practise writing SQL queries and understand how to retrieve and analyse data from multiple tables.
